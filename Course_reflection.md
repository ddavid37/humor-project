*Course Reflection*

What went well: Building three connected apps over the semester was a good way to learn full-stack development. Each week built on the last one so it never felt like starting from scratch. By the end I was comfortable with Next.js, Supabase, and Vercel.

What I enjoyed: The humor flavor part was genuinely fun — creating "Sarcastic News Anchor" and seeing what captions it generated made the project feel less like homework. The user testing was also useful; I wouldn't have noticed the upload button confusion without watching someone else use my app.

What I didn't enjoy: Debugging Vercel deployment issues. Things would build fine locally and then fail on Vercel for config reasons (tsconfig paths, root directory settings). It was time-consuming and not very educational.

Suggestion: A short guide on common Vercel/monorepo deployment pitfalls early in the course would save a lot of debugging time. Most of the issues I hit (environment variables, root directory config, tsconfig excludes) follow the same patterns.
